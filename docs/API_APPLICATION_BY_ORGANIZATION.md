# 공공데이터포털 기관별 API 신청서

> 각 기관별로 따로 신청해야 합니다.
> 아래 내용을 복사하여 각 기관별로 공공데이터포털에서 신청하세요.

---

## 1️⃣ 법제처 신청서

### 기관명
법제처

### 공공데이터 명
국가법령정보 (건축·주택·부동산 관련)

### 공공데이터 내용
국가법령정보에서 건축법, 주택법, 도시계획법, 개발제한구역법, 녹색건축물조성법 등 건축·주택·부동산 관련 법령을 검색하고 조회합니다. 건축사, 설계자, 건축주가 각 법령의 최신 개정사항을 확인하고 관련 조항을 조회할 수 있도록 통합 정보 제공 서비스에 활용됩니다.

### 활용 목적
산업·기술

### 데이터 활용 목적 (상세 설명)
건축, 부동산, 도시개발 관련 공간정보 통합 분석 서비스 개발 시 건축법, 주택법, 도시계획법, 개발제한구역지정및관리에관한특별법, 녹색건축물조성지원법, 건설기술진흥법, 건축기본법 등 핵심 법령의 최신 정보를 실시간 제공합니다. 건축사, 설계자, 건축주가 부지 검토, 기본설계, 인허가 검토 단계에서 관련 법령의 요구사항을 신속하게 조회하여 법령 미충족 위험을 조기에 발견하고 설계·인허가 오류를 감소시킵니다.

## 2️⃣ 국토교통부 (토지·부지정보) 신청서

### 기관명
국토교통부

### 공공데이터 명
공간정보 통합 조회 서비스, 토지특성정보, 지목분류 및 토지대장정보

### 공공데이터 내용
주소 기반으로 토지의 특성정보(지번, 지목, 면적, 표준지공시지가, 개별공시지가)를 조회하고, 지번과 도로명주소 간 상호 변환을 수행합니다. 대규모 택지개발사업 현황정보도 제공받습니다.

### 활용 목적
산업·기술

### 데이터 활용 목적 (상세 설명)
부지 검토 단계에서 주소 입력만으로 토지의 기본정보(지번, 지목, 면적)와 공시지가 정보를 신속하게 조회할 수 있는 통합 정보 제공 서비스를 개발합니다. 건축주와 설계자가 부지 선정 단계에서 토지의 가격, 특성, 개발 가능성을 사전에 파악하여 기본설계 오류를 감소시키고 사업성을 신속하게 검토하도록 지원합니다.

## 3️⃣ 국토교통부 (건축·건물정보) 신청서

### 기관명
국토교통부

### 공공데이터 명
건축물대장 정보 서비스, 건축인허가정보, 적법한건축물정보

### 공공데이터 내용
기존 건물의 준공년도, 층수, 지하층, 구조, 용도, 건폐율, 용적률 등 상세 정보를 조회합니다. 건축물 인허가 현황 및 적법성 여부를 확인할 수 있습니다.

### 활용 목적
산업·기술

### 데이터 활용 목적 (상세 설명)
기존 건물의 건축물대장 정보를 조회하여 건물의 구조, 용도, 건폐율, 용적률, 준공년도 등을 파악합니다. 용도변경, 증축, 개보수 계획 시 기존 건물 정보를 사전 검토하여 설계 오류를 방지하고, 인허가 과정에서 기존 건물의 적법성을 확인하여 법적 리스크를 감소시킵니다.

## 4️⃣ 국토교통부 (도시계획·용도지역) 신청서

### 기관명
국토교통부

### 공공데이터 명
도시계획정보, 지구단위계획정보, 건축선정보, 세부도시계획현황정보

### 공공데이터 내용
용도지역, 용도지구, 지구단위계획, 건축선, 건축높이, 주차율 등 도시계획상 규제사항을 조회합니다. 도시계획 변경 현황, 정비구역, 재개발·재건축 구역 정보도 포함됩니다.

### 활용 목적
산업·기술

### 데이터 활용 목적 (상세 설명)
부지의 용도지역·용도지구를 조회하여 가능한 건축용도를 파악합니다. 지구단위계획이 있는 지역의 경우 건축선, 건축높이, 건축면적, 주차율 등 상세 규제를 확인하여 설계단계에서 도시계획 기준을 준수하도록 지원합니다. 정비구역, 재개발·재건축 구역 현황을 파악하여 향후 개발 가능성을 검토하도록 돕습니다.
