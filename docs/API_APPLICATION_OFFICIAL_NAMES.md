## 📝 공통 신청 정보 (모든 API 공통 입력)

### 활용 목적
산업·기술

### 활용 분야
건설/부동산 정보 서비스

### 데이터 활용 목적 (공통 템플릿)
공간정보 통합 분석 및 건설·부동산 정보 서비스 개발에 활용. 건축주, 건축사, 설계자, 시공자 등 건설업계 종사자를 대상으로 부지 검토, 기본설계, 인허가 검토 단계에서 필요한 종합 정보를 제공하여 정보조회 시간 단축, 설계 오류 감소, 인허가 기간 단축을 실현함.

## 📝 신청 시 주의사항

1. **건축HUB API 우선**: 기존 별도 API들이 건축HUB로 통합 중이므로 신규는 건축HUB 시리즈로 신청
2. **WMS/WFS**: 지도 시각화용 (QGIS, OpenLayers 호환)
3. **OpenAPI vs 파일**: OpenAPI가 가능한 경우 OpenAPI 우선 (실시간 연동)
4. **표준데이터(/standard.do)**: 행안부 발행, CSV/JSON/XML 동시 제공
5. **VWorld 계열**: 별도 VWorld 사이트 인증키도 필요할 수 있음
