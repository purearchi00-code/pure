[공공데이터포털 신청 양식 - 복사용 텍스트]

========================================
1. 서비스명
========================================
공간정보 통합 분석 및 건설·부동산 정보 서비스


========================================
2. 서비스 설명 (300자 이상)
========================================
부동산 및 건설 관련 공간정보를 통합 분석하여, 토지·건물·법령정보를 한눈에 조회할 수 있는 종합 정보 제공 서비스입니다. 건축주, 건축사, 설계자, 시공자 등 건설업계 종사자를 대상으로 부지 검토, 기본설계, 인허가 검토 단계에서 필요한 종합적인 정보를 신속하게 제공하여 설계 오류 감소, 인허가 기간 단축, 건설사업 비용 최적화를 실현합니다. 주소 기반으로 토지특성, 용도지역, 도시계획규제, 건축기준, 환경정보, 자연재해 정보, 법령 등을 통합하여 제공함으로써 건설산업의 효율성을 높이고 사회적 비용을 절감합니다.


========================================
3. 필요한 API 목록 (공공데이터포털, 법제처)
========================================

[법령 정보]
- 법제처 국가법령정보 API
- 법제처 생활법령정보 API

[부지·토지정보 - 국토교통부]
- 공간정보 통합 조회 서비스 (주소↔좌표, 토지특성)
- 토지특성정보 (표준지공시지가, 개별공시지가)
- 지목분류 및 토지대장정보
- 대규모택지개발사업정보

[건축·건물정보 - 국토교통부]
- 건축물대장 정보 서비스
- 건축인허가정보
- 적법한건축물정보

[도시계획 및 용도지역 - 국토교통부]
- 도시계획정보 (용도지역·용도지구·지구단위계획)
- 지구단위계획정보
- 건축선 정보
- 세부도시계획현황정보

[건축기준 및 설계기준]
- 건축기준코드 (한국건설기술연구원)
- 건축설계 기준집 (공공건축, 교육시설, 의료시설, 노인요양, 유아시설 등)

[안전 및 접근성 기준]
- 장애인·노인·임산부 편의증진 기준 (국토교통부/보건복지부)
- 소방안전기준 (소방청)
- 승강기 안전기준 (국토교통부)

[환경·생태정보 - 환경부/산림청]
- 토양환경기준 및 오염도정보
- 수질정보 (한강·낙동강·금강·영산강 수계)
- 대기환경정보
- 자연공원정보
- 습지보호지역정보
- 산림보호지역 및 산림자원정보

[자연재해정보]
- 홍수위험지도 (침수예상도, 홍수위험도)
- 지진위험도 및 발생이력
- 산사태취약지역 현황
- 지반환경정보 (지반분류, 지층, 침하위험도)

[법적·행정정보]
- 건축허가·승인 현황
- 용도변경 승인 현황
- 건설사업관리기술사 등록정보

[대규모프로젝트정보]
- 뉴타운·도시재생사업정보
- 택지개발사업지역정보
- 광역철도·도로 계획정보

[부동산가격정보]
- 표준지공시지가 및 개별공시지가
- 부동산거래가격 추이


========================================
4. 활용 분야 / 산업
========================================
건축설계, 부동산개발, 도시계획, 건설관리, 부동산컨설팅, 정책수립


========================================
5. 활용 대상 / 이용자
========================================
건축주, 건축사, 설계자, 건설사, 부동산개발업체, 도시계획 담당자, 건설컨설팅업체, 부동산 관련 전문가


========================================
6. 예상 활용 효과
========================================
- 정보조회 시간 단축 (기존 3-5시간 → 수분)
- 설계·인허가 오류 감소 (법령 미충족, 기준위반 사전방지)
- 건설사업 비용 및 일정 최적화
- 건설산업 전반의 효율성 증대
- 부실시공 및 법적분쟁 감소를 통한 사회적 비용 절감


========================================
7. 기술 구성 (선택사항)
========================================
Next.js 14 기반 풀스택 웹애플리케이션
- Frontend: React 18, TypeScript, Tailwind CSS
- Backend: Node.js API Routes
- 데이터베이스: PostgreSQL
- API 통합: REST API, OpenAPI 표준 준수
- 배포: Vercel / AWS


========================================
8. 개인정보 보호 및 보안 정책
========================================
- API 키 및 인증정보는 환경변수로 관리
- HTTPS/TLS 기반 통신
- 지번 기반 조회만 수행 (개인정보 미저장)
- 조회 로그 관리 및 감시
- 서비스 폐지 또는 변경 시 사전 공지


========================================
9. 기타 사항 (선택사항)
========================================
- 서울시 자치법규정보시스템 데이터 통합 예정
- 향후 추가 지자체 조례정보 확대 계획
- 단계별 마이그레이션: Mock 데이터 → 실제 API 연동
- 법제처 국가법령정보 및 공공데이터포털 API 우선 통합
