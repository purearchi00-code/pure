## 1️⃣ 법제처 신청서

### 기관명
법제처

### 공공데이터 명
법제처_국가법령정보 공유서비스

### 공공데이터 내용
한국의 건축법, 주택법, 도시계획법, 개발제한구역지정및관리에관한특별법, 녹색건축물조성지원법, 건설기술진흥법, 건축기본법 등 건축·주택·부동산 관련 법령의 최신 정보를 제공합니다.

### 활용 목적
산업·기술

### 데이터 활용 목적 (상세 설명)
공간정보 통합 분석 서비스에서 건축, 부동산, 도시개발 관련 법령 정보를 실시간으로 제공하여, 건축사, 설계자, 건축주가 부지 검토, 기본설계, 인허가 검토 단계에서 관련 법령의 최신 요구사항을 신속하게 조회하고 법령 미충족 위험을 조기에 발견할 수 있도록 지원합니다.
