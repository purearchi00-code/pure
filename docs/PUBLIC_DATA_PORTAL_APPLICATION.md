## 2. 서비스 개요

### 서비스명
공간정보 통합 분석 및 건설·부동산 정보 서비스

### 서비스 설명
부동산 및 건설 관련 공간정보를 통합 분석하여, 토지·건물·법령정보를 한눈에 조회할 수 있는 종합 정보 제공 서비스. 건축주, 건축사, 설계자, 시공자 등 건설업계 종사자를 대상으로 부지 검토, 기본설계, 인허가 검토 단계에서 필요한 종합적인 정보를 신속하게 제공합니다.

### 기대효과
- 부동산/건설 정보 조회 시간 단축 (기존 5단계 → 통합조회)
- 법령 미충족 위험 조기 발견
- 설계·인허가 오류 감소
- 건설사업 비용 및 일정 최적화

## 3. 필요한 API 및 데이터셋

### ⚖️ 법령 정보 (법제처)

1. **국가법령정보 (법제처)**
   - 법령 본문 검색 및 조회
   - 건축법, 주택법, 도시계획법 등 핵심 법령 기본 정보

2. **생활법령정보 (법제처)**
   - 시민/건축사를 위한 건축 관련 법령 해설

---

### 🏗️ 부지·토지정보 (국토교통부)

1. **공간정보 통합 조회 서비스**
   - 주소 ↔ 좌표 변환 (지번, 도로명주소, 건물번호)
   - 토지특성, 용도지역, 지목 조회

2. **토지특성정보**
   - 표준지공시지가, 개별공시지가, 지가변동율

3. **지목분류 및 토지대장정보**
   - 토지의 지목(대지, 논, 밭 등) 및 대장 정보

4. **대규모 택지개발 사업 정보**
   - 택지개발 사업지역, 토지이용규제 현황

---

### 🏢 건축·건물정보 (국토교통부)

1. **건축물대장 정보 서비스**
   - 건물 준공년도, 층수, 지하층, 구조, 용도, 건폐율, 용적률
   - 건축물 기본정보 및 부속정도 조회

2. **건축인허가정보**
   - 건축물 인허가 현황 및 이력

3. **적법한 건축물 정보**
   - 신고/검사 필수 건축물 현황
   - 건축법 위반 여부 사전 검토

---

### 📐 도시계획 및 용도지역 (국토교통부)

1. **도시계획정보 (도시계획 통합정보시스템)**
   - 용도지역·용도지구·지구단위계획 정보
   - 용도 변경 규제 및 건축 제한사항

2. **지구단위계획정보**
   - 지역별 지구단위계획 상세정보
   - 건축선, 건축높이, 건축면적, 주차율 규제

3. **건축선 정보**
   - 도시계획상 건축선 현황

4. **세부 도시계획 현황**
   - 정비구역, 재개발·재건축 구역 정보

## 5. 활용 계획 및 기대효과

### 주요 활용처
- 건축주, 건축사, 설계자, 건설사 등 건설산업 종사자
- 부동산 관련 컨설팅업체
- 도시계획 수립 담당자

### 활용 방식
1. **통합 정보 조회**: 단일 주소 입력으로 토지, 건물, 법령, 규제 정보 동시 조회
2. **위험도 분석**: 부지 검토 단계에서 법령 미충족 위험요소 조기 발견
3. **설계·인허가 검토**: 건축기준, 도시계획, 환경기준 등 종합 검토
4. **정책수립 지원**: 도시계획 및 지역개발 정책수립 시 기초자료 활용

### 기대효과
- 정보조회 시간 단축: 평균 3-5시간 → 수분
- 건설사업 오류 감소: 법령 미충족, 설계기준 위반 사전 방지
- 사회적 비용 절감: 부실시공, 법적분쟁 감소

## 6. 기술 구성

### 개발 환경
- **Frontend**: Next.js 14, React, TypeScript, Tailwind CSS
- **Backend**: Next.js API Routes, Node.js
- **Database**: PostgreSQL (향후 확장 예정)
- **배포**: Vercel / AWS

### API 통합 방식
- REST API 기반 데이터 수집
- 법제처, 공공데이터포털, 각 부처 OpenAPI 연동
- 데이터 캐싱 및 통합 분석 엔진

### 데이터 보안
- API 키 환경변수 관리 (.env)
- HTTPS/TLS 기반 통신
- 개인정보 최소화 원칙 준수 (지번 기반 조회만 사용, 개인정보 미저장)
